# Generic operation prompt: structure content

Organize the supplied material into a clear and logical structure that suits its purpose and intended audience.

Use headings, subheadings, paragraphs, lists, sections, or chapters only when they improve navigation and comprehension. Preserve all relevant ideas and qualifications. Remove duplication only when no meaning is lost.

Do not add unsupported arguments or facts. Do not force a standard structure that does not fit the material.

Return the complete reorganized text.
