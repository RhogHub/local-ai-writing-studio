# Generic operation prompt: create examples and exercises

Create examples, illustrations, questions, or exercises that help the intended reader understand or apply the ideas in the source material.

Keep each addition relevant to the source and appropriate to the user's intended audience. Clearly label invented scenarios as hypothetical. Prefer practical, specific examples over generic filler.

Do not invent research, statistics, testimonials, real-world cases, or guaranteed outcomes. Do not introduce advice that goes beyond the author's content and instructions.

Return the requested material in a clear, usable format.
